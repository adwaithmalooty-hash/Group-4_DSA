QUESTION 4 - EXPRESSION TREE

Postfix expression: 8 3 2 * + 6 2 / -

Expression Tree:

             -
           /   \
          +     /
         / \   / \
        8   * 6   2
           / \
          3   2

Evaluation:
3 * 2 = 6
8 + 6 = 14
6 / 2 = 3
14 - 3 = 11

Final result = 11

Comparison:
Stack-based postfix evaluation uses a stack and directly evaluates the expression.
Expression tree evaluation uses a binary tree and evaluates recursively.
Both have O(n) time complexity and O(n) space in the general case.
The expression tree provides additional structural information and supports
inorder, preorder and postorder traversal.
